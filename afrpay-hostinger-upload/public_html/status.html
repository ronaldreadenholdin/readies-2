AfrPay Live API

Hostinger upload is live on this domain. This is the adjusted API Bob uploads to public_html.

Check API status:

/api/afrpay/status

After green pre-flight, set in .env:

AFRPAY_TEST_APPROVED=true
AFRPAY_OR001_TEST_APPROVED=true
AFRPAY_OB003_TEST_APPROVED=true
AFRPAY_LIVE_ENABLED=true

Full steps: see GO_LIVE.txt in this folder.

Create payment (OR001)

POST /api/afrpay/OR001/payments
Content-Type: application/json

{
  "merchant_reference": "ORDER-10001",
  "customer_reference": "CUST-500",
  "amount_minor": 10000,
  "currency": "EUR",
  "success_url": "https://your-domain.com/success",
  "failure_url": "https://your-domain.com/failure",
  "idempotency_key": "ORDER-10001-OR001",
  "metadata": { "target_asset": "USDT", "exchange_wallet_reference": "wallet_123" }
