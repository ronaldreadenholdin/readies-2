HOSTINGER UPLOAD INSTRUCTIONS

1. Log in to Hostinger hPanel.
2. Open File Manager.
3. Open the website folder: public_html
4. Upload all files from this folder into public_html:
   - index.html
   - provider-test-board.html
5. Open your domain in the browser.

The board will open at:
https://your-domain.com/

Or directly at:
https://your-domain.com/provider-test-board.html

No backend is required. This is a standalone static HTML test board.
