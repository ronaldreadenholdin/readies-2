HOSTINGER / 0609 PATH — BOB C
=============================

Live document root:
  /var/www/html/adapter/public

Upload BOB C here only:
  /var/www/html/adapter/public/bob-c/

Do not empty /var/www/html/adapter/public
Do not overwrite index.php or the existing Laravel site.
Cancel the old Replit Bob completely. Keep only BOB C at /bob-c/
Run remove-replit-bob.sh on the server. See REMOVE-REPLIT-BOB.md.

Download ZIP on the VPS (flat pack, unzip into bob-c):

https://github.com/ronaldreadenholdin/readies-2/raw/okepaybob-c-sidebar-06bd/bob-c-vps.zip

```bash
mkdir -p /var/www/html/adapter/public/bob-c
curl -fL "https://github.com/ronaldreadenholdin/readies-2/raw/okepaybob-c-sidebar-06bd/bob-c-vps.zip" -o /tmp/bob-c-vps.zip
python3 -c "import zipfile; zipfile.ZipFile('/tmp/bob-c-vps.zip').extractall('/var/www/html/adapter/public/bob-c')"
cp -n /var/www/html/adapter/public/bob-c/.env.example /var/www/html/adapter/public/bob-c/.env
```

On the VPS, deploy the files first:

```bash
curl -fsSL "https://raw.githubusercontent.com/ronaldreadenholdin/readies-2/okepaybob-c-sidebar-06bd/deploy-bob-c.sh" -o /tmp/deploy-bob-c.sh
bash /tmp/deploy-bob-c.sh /var/www/html/adapter/public/bob-c
```

Or create folder if missing:
   /var/www/html/adapter/public/bob-c/

2. Upload EVERYTHING from hostinger/public_html/bob-c/ into that folder:
   - index.php
   - api.php
   - .htaccess

   - storage/
   - work/

3. In /var/www/html/adapter/public/bob-c/ copy .env.example to .env

4. Edit .env:
   APP_URL=https://0609.readies.biz

   XAI_BASE_URL=https://api.x.ai/v1

5. Open:
   https://0609.readies.biz/bob-c/?token=YOUR_TOKEN

6. In the 0609 sidebar (old Replit Bob), change the link to /bob-c/
   Layout file is usually:
   /var/www/html/adapter/resources/views/layouts/adminpanel.blade.php
